🐾 VetCare - Hospital Veterinário e Centro Diagnóstico

Projeto desenvolvido como atividade prática de desenvolvimento front-end, simulando uma entrega profissional para a clínica veterinária fictícia VetCare. O foco principal deste projeto é a aplicação de boas práticas de arquitetura CSS, semântica HTML5, acessibilidade, responsividade e padrões de design.

📌 Visão Geral e Objetivo

O objetivo do projeto é construir uma landing page institucional responsiva e acessível para a VetCare, permitindo que tutores de animais de estimação conheçam a infraestrutura, a equipe médica, as especialidades e tirem dúvidas frequentes.

Principais Destaques

Layout fluído e responsivo adaptado para mobile, tablet e desktop.

Estilização baseada na convenção BEM (Block Element Modifier).

Separação rigorosa de responsabilidades (HTML puramente semântico, sem CSS inline ou tags <style>).

Uso de variáveis CSS (:root) para centralizar o Design System.

Tipografia escalável utilizando a unidade rem e escala proporcional na raiz (html).

🛠️ Tecnologias e Conceitos Aplicados

HTML5 Semântico: Utilização de tags como <header>, <nav>, <main>, <section>, <article>, <details>, <summary> e <footer>.

CSS3 Moderno:

Layouts dinâmicos com Flexbox.

Variáveis/Tokens de Design CSS (:root).

Metodologia de nomenclatura BEM.

Animações e microinterações (:hover, transition, box-shadow).

Media Queries para responsividade.

Google Fonts: Importação e aplicação da fonte Poppins (pesos 400, 500, 600, 700).

API do WhatsApp: Integração do botão flutuante para contato direto via WhatsApp oficial da instituição SENAI Henrique Lupo.
